# Nigeria City Search

A responsive city search application built with Next.js, TypeScript, Tailwind CSS, React Hook Form and TanStack Query.

## Features

- Search Nigerian cities
- Debounced search
- Search results dropdown
- Loading and error states
- City details view
- Clear selected city
- Responsive UI

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- TanStack Query
- React Hook Form
- Nominatim / OpenStreetMap

## Getting Started

npm install
npm run dev

Open http://localhost:3000

## API

Location data is provided by Nominatim / OpenStreetMap.

This project follows the Nominatim usage policy and is intended as a demonstration application.
